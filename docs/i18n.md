# English UI messages and formatting

Pi Web uses a small internal message layer for its English interface. It keeps
visible text in one package and supports runtime interpolation without adding an
i18n dependency.

The interface does not select a language from browser preferences. It removes
the retired `pi-locale` local storage value when the application loads, and the
root document remains `<html lang="en">`.

## Using messages in a component

Client components get the message function from `useI18n`:

```tsx
import { useI18n } from "@/hooks/useI18n";

export function ExampleButton() {
  const { t } = useI18n();

  return <button aria-label={t("example.open")}>{t("example.open")}</button>;
}
```

The component must render below `I18nProvider`. The application root already
provides it in `app/page.tsx`.

Use parameters for runtime values instead of joining message fragments:

```tsx
<span>{t("session.messageCount", { count: messageCount })}</span>
```

The corresponding message in `lib/i18n/messages/en.ts` can use `{count}`:

```ts
"session.messageCount": "{count} messages"
```

## Adding or changing UI text

1. Add a stable key to `lib/i18n/messages/en.ts`.
2. Put the key under a feature namespace such as `chat.*`, `files.*`, or
   `settings.*`.
3. Use `t("namespace.key")` for visible text, titles, accessible labels, and
   placeholders.
4. Use interpolation for counts, names, paths, and other runtime values.
5. Keep product names, model names, provider names, commands, file paths, user
   content, tool output, and server-provided error details unchanged.
6. Do not translate an API error by matching its text. Format only the local UI
   fallback around it.

When a key is missing, the formatter returns the key and logs a development
warning.

## Dates, times, and numbers

Pi Web-owned dates, relative times, and numbers must use an explicit English
locale. Time-of-day displays must also set `hourCycle: "h23"` so they always use
a 24-hour clock. Shared date and relative-time formatters belong in
`lib/i18n/format.ts`.

Do not reformat user content, model output, filenames, session names, extension
content, or server-provided values.

## Notifications

Pi Web-owned browser and Web Push notification text comes from the English
message package. New push subscriptions do not store a locale. Existing
subscriptions can still contain a legacy `locale` field; notification delivery
must ignore it and send English text.
