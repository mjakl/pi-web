## 1. Slash command menu

**Trigger / filter.** `slashQuery` = text after `/` when `value` starts with `/` and contains no whitespace after it, lowercased; otherwise `null` — `ChatInput.tsx:1083-1086`. Any whitespace closes the menu (so `/name foo` is not a menu state). Menu open/reset is a pure effect on `slashQuery`: opens, resets active index to 0, and fires `onLoadSlashCommands()` once per open-cycle (`slashCommandsRequestedRef`) — `ChatInput.tsx:1646-1661`.

**Sources.**
- Built-ins are a client-side constant: `compact`, `reload`, `name`, `session` (`availableWhileStreaming`), `copy` (`availableWhileStreaming`), `clone` — `ChatInput.tsx:232-249`. Descriptions are i18n keys (`chat.commandCompact` …) resolved via `getSlashDescription` — `ChatInput.tsx:315-322`, strings at `lib/i18n/messages/en.ts:299-305`.
- Everything else comes from the `get_commands` RPC — `useAgentSession.ts:1013-1034` → server builds `SlashCommandInfo[]` from three SDK collections — `lib/rpc-manager.ts:1086-1109`:
  - `inner.extensionRunner.getRegisteredCommands()` → `{name: registered.invocationName, description, source:"extension", sourceInfo}`
  - `inner.promptTemplates` → `{name, description, source:"prompt", sourceInfo}`
  - `inner.resourceLoader.getSkills().skills` → `{name: "skill:"+skill.name, description, source:"skill", sourceInfo}`
  Client type `SlashCommandInfo` — `useAgentSession.ts:139-151`.
- Skill "Manual" badge: on each menu open, `GET /api/skills?cwd=<abs>` → `SkillsResponse.skills[].disableModelInvocation` map keyed by skill name; failures degrade silently — `ChatInput.tsx:1666-1689`, badge test `isManualSkillCommand` — `ChatInput.tsx:326-333`, render `ChatInput.tsx:2121-2135`. Route: `app/api/skills/route.ts:13-30` (requires `cwd`, `authorizeDirectory`).

**Filtering / ordering.** While streaming, built-ins are pre-filtered to `availableWhileStreaming` only — `ChatInput.tsx:1090-1094`. Match = `name.includes(query) || description.includes(query)` (case-insensitive) — `:1097-1101`. Sort key: `slashMatchRank` (exact name 0, name prefix 1, name substring 2, description substring 3, else 4) then source order `builtin(0) < extension(1) < prompt(2) < skill(3)` then `Intl.Collator("en",{numeric,sensitivity:"base"})` on name — `ChatInput.tsx:301-313, 294-299, 1102-1110, 148-151`. **Keyboard (menu open, not IME-composing) — `ChatInput.tsx:1494-1532`:**

- `Escape`: close menu only (`setSlashMenuOpen(false)`); next keystroke reopens it.

**Insertion.** `applySlashCommand` sets the whole value to `/{name} ` (trailing space), closes the menu, resets index, moves the caret to end on the next animation frame — `ChatInput.tsx:1348-1359`.

## 2. `@` file completion

**Token detection — `lib/file-fuzzy.ts:31-53`.** `extractAtQuery(textBeforeCursor)`: quoted form `(?:^|\s)@"([^"\n]*)$` wins, else plain `(?:^|\s)@([^\s"]*)$`. `@` must be at start or preceded by whitespace (so `foo@bar` never triggers). Returns `{start, query, quoted}`. Recomputed on every `onChange`, `onSelect` (caret move) and `onCompositionEnd` — `ChatInput.tsx:2385-2405`, via `updateAtQuery` — `:1164-1171`. With no `cwd`, only path-like queries open the menu (`cwd || isFilePathQuery(query)`).

**Mode split.** `isFilePathQuery` = `/^(?:~(?:\/|$)|\.{1,2}([\\/]|$)|\/|[a-zA-Z]:[\\/]|\\\\)/` — `lib/file-fuzzy.ts:21-23`. Path mode (`@~/`, `@/`, `@./`, `@../`, `@C:\`, `@\\`) → `/api/file-completion`; plain names → local index, and `/api/file-index?q=` when the index is truncated — `ChatInput.tsx:1173-1186`.

**`GET /api/file-index?cwd=<abs>[&q=]` — `app/api/file-index/route.ts`.** Guarded by `authorizeDirectory` (403/404/400) — `:129-136`, `lib/file-access.ts:38-63`. Listing is git-aware: `git -C cwd ls-files --cached --others --exclude-standard -z` (timeout 10 s, 64 MB buffer, `LC_ALL=C`), falling back to a BFS `readdir` walk with `isIgnoredDirent` skip list on failure/non-repo — `:48-115`, skip list `lib/file-dirent.ts:5-29` (`node_modules`, `.git`, `.next`, `dist`, `build`, `__pycache__`, `.turbo`, `.cache`, `coverage`, `.pytest_cache`, `.mypy_cache`, `target`, `vendor`, `.DS_Store`, `*.pyc`). Caps: `MAX_FILES 5000` (response), `GIT_HARD_CAP 200_000`, `WALK_HARD_CAP 50_000`, `MAX_WALK_DEPTH 8`, `MAX_QUERY_LENGTH 500` (`q` sliced), cache `CACHE_TTL_MS 10_000` / `CACHE_MAX_ENTRIES 20` on `globalThis.__piFileIndexCache` — `:20-26,38-46,138-153`. Responses: no `q` → `{files: string[] (cwd-relative), truncated: boolean}`; with `q` → `{matches: {path,isDir}[]}` ranked over the *full* listing — `:155-166`.

**`GET /api/file-completion?q=<path>[&cwd=<abs>]` — `app/api/file-completion/route.ts`.** 400 unless `isFilePathQuery(q)`, `cwd` absolute when given, and `cwd` present for `.`-relative queries — `:8-20`. Body `{matches: {path, isDir}[]}`, `Cache-Control: no-store`. Errors map ENOENT/ENOTDIR→404, EACCES/EPERM→403, else 500, body `{error:"Cannot list directory"}` — `:28-38`. `completeFilePath` lists **immediate children only**, includes hidden files, case-insensitive prefix match, sorts directories first then `localeCompare("en")`, caps at **20**, resolves symlink dir-ness via `stat`, and returns **absolute** paths (`path.join(directory, name)`) — `lib/directory-browser.ts:57-89`; `~`/`.`/`..` are normalized to `~/`, `./`, `../` first; `~` → `homedir()` via `normalizeDirectory` — `:45-55`.

**Client fetch policy.** Index fetched when an `@` token is active, not path mode, `cwd` set, and the cached index for that cwd is older than 10 s; a single in-flight fetch per cwd; failure keeps the old index — `ChatInput.tsx:1256-1286`. Query searches (both path mode and truncated-index mode) are debounced 150 ms with `AbortController` — `:1187-1225`. A server result is used only when cwd+query still match; a failed path-mode result is used (renders "Cannot list this directory"), a failed index search falls back to local matches — `:1227-1235, 2236-2242`.

**Scoring — `lib/file-fuzzy.ts:96-138`.** `buildEntriesFromFiles` derives directory entries from file paths and sorts shallow-first then alphabetical (`:58-88`). `scoreEntry`: if the query contains `/`, score against the full path (exact 100 / prefix 80 / substring 50 / subsequence 10); else against the basename (exact 100 / prefix 80 / substring 50 / path-substring 30 / subsequence 10). Directories get `+10` when score > 0. Ties broken by path depth then `localeCompare("en")`. `filterFileEntries` caps at `AT_RESULT_LIMIT = 20`; an empty query returns the first 20 in base order.

**Insertion — `buildAtInsertText` (`lib/file-fuzzy.ts:154-172`) applied by `applyAtCompletion` (`ChatInput.tsx:1288-1317`).**
- File: `@path ` (trailing space closes the token → menu hides); quoted `@"path" ` when the path contains a space or the token was already quoted; caret after the space.
- Directory: `@dir/` with **no** trailing space so drill-down continues (the `dir/` query then prefix-matches its children); quoted directories insert closed `@"dir/"` with the caret placed *before* the closing quote.
- Replacement spans `[atQuery.start, caret)`; when completing inside a quoted token a following `"` is consumed — `:1293-1300`.
- After `setValue`, the token is re-derived manually (`setAtQuery(extractAtQuery(...))`) since `setValue` fires no `onChange` — `:1308`.

**Keyboard (menu open, not composing) — `ChatInput.tsx:1536-1559`:** `ArrowDown`/`ArrowUp` move the clamped active index; `Escape` closes the menu only; `Tab` **or** the send shortcut applies the active entry. Active item is scrolled with `scrollIntoView({block:"nearest"})` — `:1329-1335`.

**One-shot inserts** (file explorer buttons, always closed form, directories get `/` and a trailing space): `buildAtMentionText` / `buildFileLineMentionText` (`@path:12`, `@path:12-30`) — `lib/file-fuzzy.ts:179-202`, called through `ChatInputHandle.insertText` — `components/AppShell.tsx:515-535`, handle impl `ChatInput.tsx:889-910` (inserts at caret, adds a leading space if the preceding char isn't one).

**Rendering of references** — `lib/file-links.ts`: `resolveLocalFileHref(href, baseDir, relativeRoot)` (`:69-127`) rejects `/api/*`, `/_next/*`, non-`file:` schemes and UNC-looking `//`, accepts `file:` URLs, drive-absolute, root-absolute, and relative hrefs (relative ones must stay inside `relativeRoot`, `isPathInside` `:33-45`), strips a `:line[:col]` suffix (`:3-5`) and normalizes `.`/`..` without touching the filesystem (`normalizeLocalPath` `:7-31`). `resolveLocalFilePath` (`:130-171`) is the filesystem-only variant (no URL/source-location syntax), used for plain paths.

## 4. Send modes while running

**State.** `isStreaming` prop = `agentRunning || bashRunning` (`ChatWindow.tsx:399`, passed `:1033`). Derived flags — `ChatInput.tsx:1122-1128`: `canQueueStreamingMessage = text || images`; `hasStreamingActions = isStreaming && Boolean(onSteer)` (`onSteer`/`onFollowUp` are only passed while `agentRunning`, `ChatWindow.tsx:1001-1021`); `showStop = isStreaming && (!canQueueStreamingMessage || !hasStreamingActions)` — i.e. during a bash run (no `onSteer`) the button always stops.

**Choice.** Default is **steer**; Alt/Option selects **follow-up**. `queueModifier` tracks Alt via window `keydown`/`keyup` (rejecting AltGraph and IME composition) and clears on `blur`/`visibilitychange`/composition start/`isStreaming`/`draftKey` change — `ChatInput.tsx:1130-1160, 2398`. `streamingSubmissionAction = queueModifier && onFollowUp ? "followup" : "steer"` (`:1127-1128`) drives the button `data-action`, icon, `aria-label` (`chat.steer`/`chat.queue`) and title (`chat.steerTitle` "Interrupt the current run and inject this message now" / `chat.queueTitle` "Queue after the agent finishes (Option/Alt)") — `:1772-1789, 2519-2585`. Keyboard send re-reads `e.altKey` at the moment of Enter — `:1595-1600`. Pointer: `onPointerDown` records `pointerType === "touch"` and forces steer on touch (Alt is meaningless there) — `:2538-2554`.

**Dispatch — `sendQueued` `ChatInput.tsx:1361-1405`:** guards (`submissionDisabled`, image limit, empty), audio unlock, streaming-safe built-ins first, `/`-prefixed text via `onPromptWithStreamingBehavior`, otherwise `onSteer`/`onFollowUp`; `clearInput()` before the call, `queueModifier` reset.

**HTTP.** All three paths converge on `sendStreamingPrompt` → `POST /api/agent/{id}` `{type:"prompt", message, streamingBehavior:"steer"|"followUp", images?}` — `useAgentSession.ts:2809-2857`. On failure the text is restored to the draft **only** for a definite `prompt_rejected` (ambiguous transport failures are not restored, to avoid duplicate turns) — `:2843-2852`.

**Server queueing — `lib/rpc-manager.ts`.** `streamingBehavior` defaults to `"followUp"` for deferred inputs (`:629-633`). While compacting, or while any unpaused deferred input exists, a non-extension prompt is put in the wrapper's own `deferredInputs` queue and answered `{queued:true}` — `:582-588, 380-390`; the client then removes the optimistic bubble and reconciles — `useAgentSession.ts:2093-2103`. `queuedMessages()` merges the SDK queues with the wrapper's deferred inputs — `rpc-manager.ts:355-368`; every change emits `{type:"queue_update", steering, followUp}` — `:369-371`, also re-emitted on any SDK `queue_update` — `:234`. Deferred inputs drain when compaction ends (`drainDeferredInputs`, `:394-425`); an admission rejection re-inserts the item in order, pauses the queue and emits `prompt_error`.

**Queued display — `ChatInput.tsx:1810-1902`.** Panel shown when `steering.length + followUp.length > 0`; header `chat.queued` ("Queued · {count}"); one `QueuedMessageRow` per message, badge `steer` (accent border) or `follow-up`, single-line ellipsis with `title` = full text — `:487-532`. **Recall — `handleRecallQueue` `useAgentSession.ts:2896-2952`.** Single in-flight promise per composer; `POST {type:"clear_queue"}`; the reply `{steering, followUp, images?, queuedMessages}` is turned into one draft `{value: texts.join("\n\n"), images}` and handed to `ChatInputHandle.replaceDraft(draft, destinationKey)` (or `setDraft` when unmounted); the queue snapshot is only applied if no newer SSE update landed. `replaceDraft` persists first, then replaces the visible composer if the key matches — `ChatInput.tsx:768-773`, replacement bumps `imageBatchVersionRef`, revokes previous previews, clears `@`-token and history cycle, refocuses — `:726-741`.

**Server `clear_queue` — `rpc-manager.ts:1048-1075`.** Full clear only (no per-item dequeue). Drains `deferredInputs` and `inner.clearQueue()`, folds deferred texts back into `steering`/`followUp` by their `streamingBehavior`, collects their images, emits `queue_update`, returns `{steering, followUp, images?, queuedMessages}`.

## 6. Drafts, recovery, input history

### Cross-cutting notes for a server-rendered re-implementation

- Draft state, input history, the file index, and the slash command list are all client-only caches; nothing is persisted server-side, and drafts do not survive a reload today.
- The two anchored menus need only: a filtered list, a flat active index, `Tab`/`Enter` apply, `Escape` close-only-this-layer, and a max-height clamp against the nearest scroll ancestor.
- `submissionDisabled` (branch action in flight) blocks both `handleSend` and `sendQueued` and disables the primary button — `ChatWindow.tsx:1031`, `ChatInput.tsx:1061, 1363, 2531-2534`.
- `onError` surfaces attach/limit failures as app notices — `ChatWindow.tsx:997`, `useAgentSession.ts:1139-1144`.
